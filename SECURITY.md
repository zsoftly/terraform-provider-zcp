# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this provider, please do **not**
open a public GitHub issue. Report it privately by email to
[security@zsoftly.ca](mailto:security@zsoftly.ca) or through
[GitHub Security Advisories](https://github.com/zsoftly/terraform-provider-zcp/security/advisories/new).

We acknowledge receipt within 3 business days and work with you to resolve the
issue promptly.

## Scope

This policy covers the provider source code and released binaries in this
repository. Report security issues in the ZSoftly Cloud Platform itself to
[security@zsoftly.ca](mailto:security@zsoftly.ca).

## Supported Versions

We support and provide security fixes for the latest release only.
